## 8. String to Integer (atoi) (Medium)
**Date and Time:** Jun 23, 2026

Link: https://leetcode.com/problems/string-to-integer-atoi/

<br>

### Question:
Implement the `myAtoi(string s)` function, which converts a string to a 32-bit signed integer.

The algorithm for `myAtoi(string s)` is as follows:

1. **Whitespace:** Ignore any leading whitespace (`" "`).
2. **Signedness:** Determine the sign by checking if the next character is `'-'` or `'+'`, assuming positivity if neither is present.
3. **Conversion:** Read the integer by skipping leading zeros until a non-digit character is encountered or the end of the string is reached. If no digits were read, then the result is `0`.
4. **Rounding:** If the integer is out of the 32-bit signed integer range `[-2^31, 2^31 - 1]`, then round the integer to remain in the range.

Return the integer as the final result.

<br>

**Example 1:**
> **Input:** s = "42"
> 
> **Output:** 42

**Example 2:**
> **Input:** s = " -042"
> 
> **Output:** -42

**Example 3:**
> **Input:** s = "1337c0d3"
> 
> **Output:** 1337

**Example 4:**
> **Input:** s = "0-1"
> 
> **Output:** 0

**Example 5:**
> **Input:** s = "words and 987"
> 
> **Output:** 0

<br>

#### Constraints:
* `0 <= s.length <= 200`

* `s` consists of English letters (lower-case and upper-case), digits (`0-9`), `' '`, `'+'`, `'-'`, and `'.'`.

<br>

### Walk-through:
Follow the four steps procedurally with a pointer `i`:

1. Advance `i` past all leading spaces; return `0` if the entire string is spaces.
2. Read optional `'-'` or `'+'` to set `sign`; advance `i`.
3. Collect consecutive digit characters into `digit` string; stop at any non-digit.
4. Return `0` if `digit` is empty, otherwise clamp `sign * int(digit)` to `[-2^31, 2^31 - 1]`.

<br>

### Solution
Jul 3, 2026, [Time Taken 26m 24s]
```python
class Solution:
    def myAtoi(self, s: str) -> int:
        # S: Follow the algorithm, but handle edge case 1. if s is full of empty. 2. handle res to round down to -2^31 or 2^31-1
        # TC: O(n), SC: O(n)

        # Procedural
        i = 0
        digit = ""
        # 1. Skip " "
        while i < len(s) and s[i] == " ":
            i += 1
        # Handle edge case, if s is full of empty space
        if i == len(s):
            return 0
        # 2. Update sign
        sign = 1
        if s[i] == "-":
            sign = -1
            i += 1
        elif s[i] == "+":
            i += 1
        # 3. Get digit
        while i < len(s) and s[i].isdigit():
            digit += s[i]
            i += 1
        # 4. Check if digit is empty to return 0 or no
        if not digit:
            return 0
        # 5. Check if results are in bound and round result
        res = sign * int(digit)
        if sign == -1:
            res = max(res, -2**31)
        else:
            res = min(res, 2**31-1)
        return res
```
**Time Complexity:** $O(n)$, where `n = len(s)` <br>
**Space Complexity:** $O(n)$
