## 36. Valid Sudoku (Medium)
**Update:** Jun 5, 2024, 3:38 PM (EST)

Link: https://leetcode.com/problems/valid-sudoku/

<br>

### Question:
Determine if a `9 x 9` Sudoku board is valid. Only the filled cells need to be validated __according to the following rules:__

1. Each row must contain the digits `1-9` without repetition.

2. Each column must contain the digits `1-9` without repetition.

3. Each of the nine `3 x 3` sub-boxes of the grid must contain the digits `1-9` without repetition.

**Note:**

- A Sudoku board (partially filled) could be valid but is not necessarily solvable.

- Only the filled cells need to be validated according to the mentioned rules.

### KeyPoints: 
Use three dicts to save each entry into `colSet{}, rowSet{}, boxSet{}`, loop over matrix to add entry's value into three sets, check if there is repetition exists, if so, return False. If we have `'.'`, we `continue`.

### Solution
Jul 17, 2026. [Time Taken 5m 17s]. First attempt forgot to handle boxes in a set by `[(r//3, c//3)]`.
```python
class Solution:
    def isValidSudoku(self, board: List[List[str]]) -> bool:
        # Q: Validate if the sudoku is valid
        # S: Use three sets (rows, cols, boxes) to save numbers
        # If board[r][c] != '.', check if in three sets, if not, add into three sets; if so, return False
        # TC: O(9*9), SC: O(9*9*3)
        rows, cols, boxes = collections.defaultdict(set), collections.defaultdict(set), collections.defaultdict(set)
        # Traverse board
        for r in range(len(board)):
            for c in range(len(board[r])):
                val = board[r][c]
                # Check if val is digit
                if val != '.':
                    # Check if duplicate in 3 sets
                    if val in rows[r] or val in cols[c] or val in boxes[(r//3, c//3)]:
                        return False
                    # Add into 3 sets
                    rows[r].add(val)
                    cols[c].add(val)
                    boxes[(r//3, c//3)].add(val)
        return True
```
**Time Complexity:** $O(1)$, the area of the Sudoku. <br>
**Space Complexity:** $O(1)$
