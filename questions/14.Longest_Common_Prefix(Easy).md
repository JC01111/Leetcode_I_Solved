## 14. Longest Common Prefix (Easy)
**Date and Time:** Jul 7, 2024, 17:16 (EST)

Link: https://leetcode.com/problems/longest-common-prefix/

<br>

### Question:
Write a function to find the longest common prefix string amongst an array of strings.

If there is no common prefix, return an empty string `""`.

<br>

**Example 1:**
> **Input:** strs = ["flower", "flow", "flight"]
> 
> **Output:** "fl"

**Example 2:**
> **Input:** strs = ["dog", "racecar", "car"]
> 
> **Output:** ""
>
> **Explanation:** There is no common prefix among the input strings.

**Self-added case 1:**
> **Input:** strs = ["flow", "fl"]
> 
> **Output:** "fl"

**Self-added case 2:**
> **Input:** strs = ["flow"]
> 
> **Output:** "flow"

<br>

#### Constraints:
* `1 <= strs.length <= 200`

* `0 <= strs[i].length <= 200`

* `strs[i]` consists of only lowercase English letters.

<br>

### KeyPoints: 
The way to solve it is to pick a random string (`strs[0]`) to start with, then we compare it with all the `str` in `strs` character by character, if a `len(str) == i`, which is the `i`th index of a str, or `str[i] != strs[0][i]` means there is no match for word in a `str`, we should return the current `res`; otherwise, we should update the `res`.

<br>

For this problem, this approach may seems overcomplicated, but I think this is the best approach in general.
```python
class Node:
    def __init__(self):
        self.children = {}  # {char: children}
        self.cnt = 0        # How many words have this char in common

class Solution:
    def longestCommonPrefix(self, strs: List[str]) -> str:
        # Q: Find longest common prefix among all words
        # S: 1. Build Tries for every string in strs
        # 2. Save each node in tries with a int to track how many strings have this word in common
        # 3. Search the first string in strs, check in tries for the longest common prefix, when count != len(strs), return the number
        # TC: O(n*m), n=len(strs), m=avg len(strs[i]), SC: O(n*m)

        root = Node()
        # 1. Build tries
        for word in strs:
            curr = root
            for c in word:
                # Update cnt of c for new word
                if c in curr.children:
                    curr.children[c].cnt += 1
                else:
                    node = Node()
                    node.cnt = 1
                    curr.children[c] = node
                curr = curr.children[c]
        # 2. Search the first word in tries
        curr = root
        res = ""
        cnt = len(strs)
        for c in strs[0]:
            if c in curr.children:
                # Check if cnt == len(strs)
                if cnt == curr.children[c].cnt:
                    res += c
                    print(res)
                else:
                    break
                curr = curr.children[c]
        return "" if not res else res
```
**Time Complexity:** $O(n)$ <br>
**Space Complexity:** $O(n)$

### Brute Force
```python
class Solution:
    def longestCommonPrefix(self, strs: List[str]) -> str:
        # Randomly pick one str then compare with other strs one by one
        res = ""
        for i in range(len(strs[0])):
            for str in strs:
                if len(str) == i or str[i] != strs[0][i]:
                    return res
            res += str[i]
        return res
```
**Time Complexity:** $O(n)$ <br>
**Space Complexity:** $O(n)$
