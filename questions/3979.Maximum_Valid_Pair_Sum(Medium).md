## 3979. Maximum Valid Pair Sum (Medium)
**Date and Time:** Jul 4, 2026

Link: https://leetcode.com/problems/maximum-valid-pair-sum/

<br>

### Question:
You are given an integer array `nums` and an integer `k`. A pair `(i, j)` is called **valid** if:

* `i < j`
* `j - i >= k`

Return the **maximum** value of `nums[i] + nums[j]` among all valid pairs. If no valid pair exists, return `-1`.

<br>

**Example 1:**
> **Input:** nums = [4, 1, 3, 2], k = 2
> 
> **Output:** 7
>
> **Explanation:** The valid pairs are `(0,2)` with sum `4+3=7` and `(0,3)` with sum `4+2=6`, `(1,3)` with sum `1+2=3`. Maximum is `7`.

**Example 2:**
> **Input:** nums = [1, 2], k = 3
> 
> **Output:** -1
>
> **Explanation:** No valid pair exists.

<br>

#### Constraints:
* `2 <= nums.length <= 10^5`

* `1 <= nums[i] <= 10^9`

* `1 <= k <= nums.length`

<br>

### Walk-through:
For each index `j` (starting at `k`), the best partner is the maximum of `nums[0..j-k]`. Instead of recomputing this every time, maintain a running max `prev` that expands by one element (`nums[i-k]`) as `i` advances. Then `res = max(res, prev + nums[i])`.

<br>

### My Solution:
```python
class Solution:
    def maxValidPairSum(self, nums: list[int], k: int) -> int:
        # Q: i < j and j - i >= k, find the max value of pairs
        # S: 1. Save every index into hashmap with val, {index: val}
        # Index i in dp, saves the max nums[i] in dp
        # So each time we get i - k in hashmap, we will get the max
        # TC: O(n), SC: O(n)
        prev = 0
        res = 0
        for i in range(k, len(nums)):
            val = nums[i]
            # Update prev from before i-k or i-k
            prev = max(prev, nums[i-k])
            res = max(res, prev + val)
        return res
```
**Time Complexity:** $O(n)$, where `n = len(nums)` <br>
**Space Complexity:** $O(1)$
