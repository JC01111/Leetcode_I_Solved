## 383. Ransom Note (Easy)
**Date and Time:** Jun 5, 2024, 11:56 PM (EST)

Link: https://leetcode.com/problems/ransom-note/

<br>

### Question:
Given two strings `ransomNote` and `magazine`, return `true` if `ransomNote` can be constructed by using the letters from `magazine` and `false` otherwise.

Each letter in `magazine` can only be used once in `ransomNote`.

<br>

**Example 1:**
> **Input:** ransomNote = "a", magazine = "b"
> 
> **Output:** false

**Example 2:**
> **Input:** ransomNote = "aa", magazine = "ab"
> 
> **Output:** false

**Example 3:**
> **Input:** ransomNote = "aa", magazine = "aab"
> 
> **Output:** true

<br>

### Solution
Jul 13, 2026. [Time Taken 4m 42s]
```python
class Solution:
    def canConstruct(self, ransomNote: str, magazine: str) -> bool:
        # Q: Check if ransomNote can be constructed from magazine
        # S: 1. Convert magazine into hashmap{}
        # 2. Loop over ransomNote by decrementing letter in hashmap.
        # 3. If a char not in hashmap or hashmap[c] == -1, return False
        # TC: O(n), n=len(ransomNote), SC: O(n)
        hashmap = {}
        # 1. Convert magazine into hashmap
        for c in magazine:
            hashmap[c] = hashmap.get(c, 0) + 1
        # 2. Loop over ransomNote
        for c in ransomNote:
            if c not in hashmap:
                return False
            hashmap[c] -= 1
            # Count if hashmap[c] == -1
            if hashmap[c] == -1:
                return False
        return True
```
**Time Complexity:** $O(\text{len(ransomNote)} + \text{len(magazine)})$, because we loop over `ransomNote, magazine`. <br>
**Space Complexity:** $O(\text{len(magazine)})$, because we only store elements in `magazine`.
