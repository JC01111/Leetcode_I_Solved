## 290. Word Pattern (Easy)
**Date and Time:** Nov 15, 2024, 14:10 (EST)

Link: https://leetcode.com/problems/word-pattern/

<br>

### Question:
Given a `pattern` and a string `s`, find if `s` follows the same pattern.

Here **follow** means a full match, such that there is a bijection between a letter in `pattern` and a **non-empty** word in `s`. Specifically:

* Each letter in `pattern` maps to **exactly** one unique word in `s`.

* Each unique word in `s` maps to **exactly** one letter in `pattern`.

* No two letters map to the same word, and no two words map to the same letter.

<br>

**Example 1:**
> **Input:** pattern = "abba", s = "dog cat cat dog"
> 
> **Output:** true
>
> **Explanation:** <br>
> The bijection can be established as:
> * `'a'` maps to `"dog"`.
> * `'b'` maps to `"cat"`.

**Example 2:**
> **Input:** pattern = "abba", s = "dog cat cat fish"
> 
> **Output:** false

**Example 3:**
> **Input:** pattern = "aaaa", s = "dog cat cat dog"
> 
> **Output:** false

<br>

#### Constraints:
* `1 <= pattern.length <= 300`

* `pattern` contains only lower-case English letters.

* `1 <= s.length <= 3000`

* `s` contains only lowercase English letters and spaces `' '`.

* `s` **does not contain** any leading or trailing spaces.

* All the words in s are separated by a single space.

<br>

### Walk-through: 
1. Check if length are the same after `s = s.split()`.

2. Match letter in `pattern` with a `word` in `s`.

3. If letter exists in hashmap, check if the saved word for that letter is the same as `s[i]`.

<br>

### Solution
Jul 16, 2026. [Time Taken 21m 48s]
```python
class Solution:
    def wordPattern(self, pattern: str, s: str) -> bool:
        # Q: Map a letter in pattern to a word in s
        # S: 1. Check if letter in pattern exists in hashmap
        # 2. If not, create a new match between letter: word; if don't match in s, return False
        # TC: O(n+m), SC: O(1), 26 letters
        hashmap = {}
        sSet = set()
        s = s.split()
        if len(pattern) != len(s):
            return False
        # Check
        for i in range(len(pattern)):
            if pattern[i] not in hashmap:
                if s[i] in sSet:
                    return False
                hashmap[pattern[i]] = s[i]
                sSet.add(s[i])
            elif pattern[i] in hashmap and hashmap[pattern[i]] != s[i]:
                return False
        return True
```
**Time Complexity:** $O(n)$, `n` is len(s). <br>
**Space Complexity:** $O(1)$
